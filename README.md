# AI Builders Hub

Build a prototype website for "AI Builders", a student-led AI community club at Universal AI University, under the AI Centre of Excellence (AI CoE).

TAGLINE: "Meet. Build. Begin."

MOTTO: "We learn AI by building." / "Ideas → Real Builds"

DESIGN THEME (based on the club logo):

- The logo is a robotic arm assembling colorful puzzle pieces labeled AI, MCP, RAG, LLM, API, GIT, AGENTS, MLOPS, RESEARCH, DATA.

- Style: modern, techy, playful but professional. Use a dark theme (near-black #0A0D12 background) with a white/light section for contrast.

- Accent colors taken from the puzzle pieces: purple #7C3AED, green #16A34A, red #EF4444, orange #F97316, yellow #FACC15, blue #3B82F6, teal #14B8A6, navy #0B2A5B.

- Font: Inter or Space Grotesk for headings, Inter for body.

- Visual motif: puzzle-piece shaped cards and dividers, subtle grid background, and a robotic-arm illustration or icon in the hero.

- Rounded corners, soft glow on hover, smooth scroll animations.

- Fully responsive (mobile first).

PAGES / SECTIONS (single-page with a sticky navbar):

Home, About, What We Do, Projects, Events, Team, Join Us, Footer.

Start by setting up the design system, navbar, and a placeholder for each section. Navbar: club logo on the left, links in the center, "Join Us" button on the right.
